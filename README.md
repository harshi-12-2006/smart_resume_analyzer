 Smart Resume Analyzer

An advanced, context-aware resume evaluator that moves beyond rigid keyword matching to analyze the actual depth of candidate experience, projects, and execution skill-gaps using Generative AI.

Problem Statement:
Traditional Application Tracking Systems (ATS) reject qualified candidates simply because they lack specific keyword strings. Conversely, candidates frequently mask lack of technical depth by listing buzzwords. This project evaluates semantic context—matching the depth of responsibilities and technical projects against rigorous job requirements.

 Key Features
Semantic Analysis: Evaluates project descriptions and role scopes rather than just counting words.
Dynamic Scoring Dashboard: Provides an overall fit metric out of 100 based on career depth alignment.
Actionable Gap Analysis: Highlights exact technical tools or statistical frameworks missing from the resume.
Feedback Loop: Generates clear text-based optimization steps for applicants.

 Tech Stack
Frontend/UI: Streamlit (Python)
AI Engine: Google Gemini 2.5 Flash API
Document Processing:** PyPDF Text Extraction Pipeline
